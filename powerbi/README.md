# powerbi/

Power BI dashboard file(s) and supporting assets.

- `dashboard.pbix` — the main Power BI file (add once built).
- Screenshots or a short screen-recording GIF of the dashboard are worth adding here too —
  GitHub can't render `.pbix` previews, so visuals help anyone browsing the repo understand
  the result without opening Power BI.

> `.pbix` files can get large. If size becomes an issue, consider Git LFS, or simply not
> committing the .pbix and instead linking to a Power BI Service published report.
